# Roadmap

Статус: **1.0.2** (2026-11-07). Плагин установлен и используется в Web GUI DeepSeek Harness.

## Сейчас

- [x] Тарифы Peak/Off-Peak по официальной документации DeepSeek.
- [x] USD- и CNY-таблицы без валютных курсов.
- [x] Определение региона по IANA-таймзоне и locale.
- [x] Стоимость текущей сессии по provider-reported usage.
- [x] Разделение Peak/Off-Peak, Flash/Pro и unpriced-токенов.
- [x] Скрытие для неофициальных моделей и провайдеров.
- [x] Popover с расшифровкой по клику.
- [x] Юнит-тесты и документация на русском.

## Не входит в цели

- Конвертация USD/CNY в RUB или другие валюты по стороннему курсу.
- Выдуманные или «примерные» тарифы для моделей без официальной публикации.
- Подмена штатной строки usage.
- Сетевые запросы из плагина для получения цен или курсов.
- Бухгалтерский или налоговый учёт: плагин показывает оценку, а не счёт DeepSeek.

## Правила обновления roadmap

1. Задачи P0 должны быть привязаны к внешнему событию (новая документация, новый год, релиз Harness) или к дефекту.
2. Перед добавлением задачи проверить, что она не дублирует README/AGENTS.
3. При завершении задачи обновить `CHANGELOG.md` и, если меняется поведение, README.
