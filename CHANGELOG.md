## [1.0.4] — 2026-11-08

### Изменено

- Основная установка — по короткой ссылке на репозиторий `https://github.com/kachanov-e-v/dsh-token-pricing`; `install_bundle` сохраняет её в профиле как `github:kachanov-e-v/dsh-token-pricing` с привязкой к коммиту.
- Архивная ссылка на релизный тег `vX.Y.Z` остаётся для воспроизводимой установки.

### Документация

- README, `AGENTS.md` и `docs/MAINTENANCE.md` переведены на короткую GitHub-ссылку.

## [1.0.3] — 2026-11-08

### Изменено

- Установка и обновление выполняются по GitHub-ссылке: `install_bundle` принимает URL архива ветки `main` или релизного тега `vX.Y.Z`. Локальный путь остаётся вариантом для разработки.
- Проверено на DeepSeek Harness `0.2.2-rc.1`.

### Документация

- README, `AGENTS.md` и `docs/MAINTENANCE.md` переведены на установку по GitHub-ссылке; описан порядок обновления через `remove_bundle` и повторную установку.

## [1.0.2] — 2026-11-07

### Изменено

- Информация по клику открывается во всплывающей панели, а не в inline-блоке.
- Панель рендерится через `createPortal`, если в клиентском runtime доступен `react-dom`; иначе используется fixed-фолбэк.
- Панель перепозиционируется при скролле и resize, закрывается по `×`, клику вне панели и `Escape`, после закрытия возвращает фокус на строку.
- Добавлены `role="dialog"`, `aria-haspopup`, `aria-expanded`, `aria-controls` и подпись закрытия.

### Документация

- README переработан в полноценное руководство пользователя и разработчика.
- Добавлены `AGENTS.md`, `ROADMAP.md`, `docs/ARCHITECTURE.md`, `docs/MAINTENANCE.md`, `LICENSE`, `CHANGELOG.md`, `.gitignore`.

## [1.0.1] — 2026-11-05

### Изменено

- Переход от раскрывающегося inline-блока к popover по клику.

## [1.0.0] — 2026-11-05

### Добавлено

- Клиент-видимая session projection `tokenPricing`.
- Раздельный учёт provider-reported usage по Peak/Off-Peak, Flash/Pro и нетарифицированным токенам.
- Региональные таблицы USD и CNY из официальной документации DeepSeek.
- Определение региона по таймзоне и locale без жёсткой привязки к Москве.
- Отображение текущего режима, местного времени и стоимости сессии под композером.
- Скрытие строки для моделей и провайдеров без опубликованного тарифа.
- Тесты тарифов, расписания, проекции и клиентских helper-функций.
